# Process artifacts

A few of the documents I used to direct the build, kept as a record of how the product took shape. Each one was pasted into an AI coding agent or used to steer the product's AI drafts. They're reproduced as written, with only line breaks adjusted for Markdown. One third-party quote and one example of unclear authorship were removed from the style guide.

| Date | Artifact | Why it's here |
|---|---|---|
| March 2025 | [Original spec: Setlist Social Feed](2025-03-original-spec.md) | The first spec. It defines the feed format and the upvote → Scheduled → Meetup RSVP loop. |
| August 2025 | [Agent instructions: automated event discovery](2025-08-discovery-agent-instructions.md) | The discovery experiment whose automatic publishing I switched off for accuracy reasons. |
| December 2025 | [Task brief: venue regions](2025-12-venue-regions-task.md) | A typical scoped change brief, with files, exact changes and an acceptance checklist. |
| March 2026 | [Amuse-Bouche writing style guide](2026-03-amuse-bouche-style-guide.md) | An early editorial voice guide, since refined into the voice rules the app's AI drafts follow. |

The originals of these files are still in `attached_assets/`, and the August 2025 instructions are also at the repository root as `AGENT_INSTRUCTIONS.md`.
